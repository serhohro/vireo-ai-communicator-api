| Version | Supported |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, please report it to us privately:

- Email: sergo87231@gmail.com
- GitHub: serhohro

We will respond within 48 hours.

## Security Best Practices

When using Vireo:

1. **Keep dependencies updated** — Run `pip install -r requirements.txt` regularly
2. **Use local execution** — Vireo is designed to run locally for privacy
3. **Review code** — Always review code before running it
4. **Report issues** — If you find something, let us know

Thank you for helping keep Vireo secure! 🔒
