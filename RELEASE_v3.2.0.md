# Vireo v3.2.0 — Rust + TypeScript SDKs + Three-Language Conformance

**AI-to-AI communication language with built-in Ed25519, DIDs, and contract lifecycle.**

*Experimental proof-of-concept — not production-ready.*

---

## North Star Achieved

Vireo now proves that **three** independently implemented AI agents can interoperate.

We added Rust and TypeScript SDKs that produce **byte-identical** output to the Python SDK for the same inputs:

- Canonical wire bytes: **226 B, identical**
- BLAKE2b-256 wire_hash: `011c2182...` — identical across all three
- Ed25519 signature: Python's signature verifies in Rust **and** TypeScript

> Specs aren't declared. They're reproduced.

## What's new in v3.2.0

### Rust SDK (`sdk/rust/`)

- **Ed25519** signatures via `ed25519-dalek` (RFC 8032)
- **BLAKE2b-256** hashing via `blake2` (RFC 7693)
- **96-byte big-endian wire header** + RFC 8785 JCS payload
- **Intent enum**: DISCOVER, PROPOSE, NEGOTIATE, COMMIT, REJECT,
  EXECUTE, VERIFY, DONE, ESCALATED, CANCELLED, FAILED, TIMEOUT
- **Envelope** + structural validator
- **Agent** with auto-derived DID
- **19/19 unit tests pass** (`cargo test`)

### TypeScript SDK (`sdk/typescript/`)

- **Ed25519** signatures via `@noble/ed25519`
- **BLAKE2b-256** hashing via `@noble/hashes`
- **RFC 8785 JCS** canonicalization via `canonicalize`
- Same 96-byte big-endian wire header
- **10/10 tests pass** (`npm test`), including 1/1 cross-language vector

### Cross-language conformance

- `tests/conformance/vectors/001_propose_commit.json`
  - Generated by `scripts/generate_test_vectors.py` via Python SDK
  - Uses RFC 8032 Ed25519 test keys (self-documenting)
- `sdk/rust/tests/test_vectors.rs` — reads the same JSON, rebuilds bytes in Rust
- `sdk/typescript/tests/test_vectors.test.ts` — reads the same JSON, rebuilds bytes in TypeScript
- All three assert byte-identical canonical bytes, wire_hash, and signature

### CI

- `.github/workflows/conformance.yml`
  - Runs Python tests (`pytest tests/conformance/`)
  - Runs Rust tests (`cargo test`)
  - Runs TypeScript tests (`npm test`)
  - Verifies vector determinism (regenerate -> identical outputs)
  - Final job `conformance-status` (North Star) gates the three

## Install

Rust:

```toml
[dependencies]
vireo-ai = "3.2.0"
```

TypeScript:

```bash
npm install @vireo-ai/sdk@3.2.0
```

## Verify locally

```bash
# Python
pytest tests/conformance/ -v

# Rust
cd sdk/rust && cargo test --test test_vectors -- --nocapture

# TypeScript
cd sdk/typescript && npm test
```

```bash

python scripts/generate_test_vectors.py

# 2. Rust verifies the same vector
cd sdk/rust
cargo test --test test_vectors -- --nocapture

# 3. TypeScript verifies the same vector
cd ../typescript
npm test
```
