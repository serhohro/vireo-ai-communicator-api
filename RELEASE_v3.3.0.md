## North Star Achieved — Three Languages, One Wire Format

Python, Rust, and TypeScript now produce byte-identical output:

- Canonical wire bytes: **226 B, identical**
- BLAKE2b-256 wire_hash: `011c2182...` — identical across all three
- Ed25519 signature: verifies across all three languages

Verified automatically on every push via GitHub Actions:
Python · Rust · TypeScript · North Star

## What's new in v3.3.0

### TypeScript SDK (`sdk/typescript/`)

- **Ed25519** signatures via `@noble/ed25519`
- **BLAKE2b-256** hashing via `@noble/hashes`
- **RFC 8785 JCS** canonicalization via `canonicalize`
- Same 96-byte big-endian wire header
- **10/10 tests pass** (`npm test`), including 1/1 cross-language vector

### Triple-language conformance

- `tests/conformance/vectors/001_propose_commit.json`
  - Generated by `scripts/generate_test_vectors.py` via Python SDK
- `sdk/rust/tests/test_vectors.rs` — rebuilds bytes in Rust
- `sdk/typescript/tests/test_vectors.test.ts` — rebuilds bytes in TypeScript
- All three assert byte-identical canonical bytes, wire_hash, and signature

### CI

- `.github/workflows/conformance.yml` — Python + Rust + TypeScript jobs
- Final job `conformance-status` (North Star) gates all three
