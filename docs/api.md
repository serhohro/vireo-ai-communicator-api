## 1. Overview

The Vireo API provides RESTful endpoints for:

- **Agent Management** — Register, list, and manage agents
- **Code Execution** — Execute Vireo code
- **Neural Networks** — Create and train neural networks
- **AI Communication** — Chat and negotiate with AI agents
- **Cryptography** — Generate keys, sign and verify messages
- **LLM Integration** — Interact with LLM providers

### Base URL
http://localhost:5000/api

text

### Response Format

All responses are in **JSON** format:

```json
{
  "status": "success|error",
  "message": "Human-readable message",
  "data": { ... }
}
HTTP Status Codes
Code	Description
200	Success
201	Created
400	Bad Request
401	Unauthorized
403	Forbidden
404	Not Found
500	Internal Server Error

3. API Endpoints
3.1 Agent Management
Register Agent
http
POST /api/agent/register
Content-Type: application/json
Request:

json
{
  "id": "agent-vision",
  "model": "qwen2.5-coder:latest",
  "capabilities": ["image_processing", "object_detection"]
}
Response:

json
{
  "status": "success",
  "agent_id": "agent-vision",
  "message": "Agent 'agent-vision' registered successfully",
  "agents": ["agent-vision"]
}
List Agents
http
GET /api/agent/list
Response:

json
{
  "status": "success",
  "agents": ["agent-vision", "agent-training"],
  "count": 2
}
Get Agent Status
http
GET /api/agent/{agent_id}/status
Response:

json
{
  "status": "success",
  "agent_id": "agent-vision",
  "model": "qwen2.5-coder:latest",
  "capabilities": ["image_processing"],
  "status": "active"
}
Add Capability
http
POST /api/agent/{agent_id}/capability
Request:

json
{
  "name": "image_processing",
  "description": "Process and analyze images"
}
Response:

json
{
  "status": "success",
  "agent_id": "agent-vision",
  "capability": "image_processing",
  "message": "Capability 'image_processing' added to 'agent-vision'"

Common Errors
Code	Description	HTTP Status
INVALID_REQUEST	Missing required fields	400
AGENT_NOT_FOUND	Agent does not exist	404

INVALID_CODE	Invalid Vireo code	400
PROVIDER_ERROR	LLM provider error	500

7. WebSocket API
Overview
Vireo supports WebSocket connections for real-time communication.

Endpoint:

text
ws://localhost:5000/ws
Message Format
json
{
  "type": "propose|commit|reject|inform",
  "sender": "agent-vision",
  "recipient": "agent-training",
  "payload": {
    "task": "Train MNIST",
    "code": "model MNIST { ... }"
  }
}
WebSocket Example
javascript
const ws = new WebSocket('ws://localhost:5000/ws');

ws.onopen = () => {
  console.log('Connected to Vireo WebSocket');
  
  // Send propose message
  ws.send(JSON.stringify({
    type: 'propose',
    sender: 'agent-vision',
    recipient: 'agent-training',
    payload: {
      task: 'Train MNIST',
      code: 'model MNIST { layer Dense(784, 128) }'
    }
  }));
};

ws.onmessage = (event) => {
  const message = JSON.parse(event.data);
  console.log('Received:', message);
};
