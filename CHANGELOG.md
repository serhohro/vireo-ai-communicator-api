## [3.2.0] — 2026-09-11

### Added
- **Rust SDK** (`sdk/rust/`) — v3.2.0
  - Ed25519 signatures via `ed25519-dalek` (RFC 8032)
  - BLAKE2b-256 hashing via `blake2` (RFC 7693)
  - 96-byte big-endian wire header + RFC 8785 JCS payload
  - Intent enum, envelope validator, Agent with auto-derived DID
  - 19/19 unit tests pass
- **Cross-language conformance test** (`sdk/rust/tests/test_vectors.rs`)
  - Reads `tests/conformance/vectors/001_propose_commit.json`
  - Asserts byte-identical canonical bytes, wire_hash, and Ed25519 signature
- **Conformance vector** `tests/conformance/vectors/001_propose_commit.json`
  - Generated by `scripts/generate_test_vectors.py` via Python SDK
  - Uses RFC 8032 Ed25519 test keys (self-documenting)
- **CI workflow** `.github/workflows/conformance.yml`
  - Runs Python tests, Rust tests, and vector determinism check

### Changed
- `scripts/generate_test_vectors.py` — rewritten for v3.1 wire format API

### Verified
- **North Star achieved:** Python ↔ Rust byte-identical for the same inputs
  - canonical wire bytes: 226 B, identical
  - wire_hash: `011c2182af8206779ae3bc4ff145467a49ae0a2389ee54f940da9de24e7255db`
  - Ed25519 signature: Python's signature verifies in Rust

### Compatibility
- Wire format v3.1 (0x0301) — unchanged
- Python SDK v3.1.0 — unchanged, 32/32 tests pass
