# Vireo for PyCharm

## Installation

1. Open PyCharm
2. Go to **Settings** → **Editor** → **File Types**
3. Click **+** (Add)
4. Name: `Vireo`
5. Extensions: `v;vireo`
6. Copy `vireo.xml` to `~/.config/JetBrains/PyCharm/filetypes/`
7. Restart PyCharm

## Features

- ✅ Syntax highlighting
- ✅ Code completion (basic)
- ✅ File type detection

## Run Script

1. Open Vireo file
2. Right-click → **Run** → **Run 'vireo'**
3. Or use terminal: `python vireo_interpreter.py file.v`
