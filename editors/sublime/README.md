# Vireo for Sublime Text

## Installation

1. Copy `Vireo.sublime-syntax` to `~/.config/sublime-text/Packages/User/`
2. Open a `.v` file
3. View → Syntax → Open all with current extension as → Vireo

## Features

- ✅ Syntax highlighting
- ✅ Comments (// and /* */)
- ✅ Strings
- ✅ Numbers
- ✅ Decorators

## Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+/ | Comment line |
| Ctrl+Shift+/ | Comment block |
