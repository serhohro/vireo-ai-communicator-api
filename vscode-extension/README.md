# 🟢 Vireo Language Extension for VSCode

Syntax highlighting, code snippets, and language support for **Vireo** — the world's first AI-to-AI communication language.

## Features

- ✅ **Syntax Highlighting** — Full color syntax highlighting for Vireo
- ✅ **Code Snippets** — Quick templates for functions, loops, neural networks
- ✅ **Language Configuration** — Auto-closing brackets, indentation rules
- ✅ **Run Scripts** — Execute Vireo scripts directly from VSCode (Ctrl+Shift+R)

## Installation

### From VSCode Marketplace (coming soon)
1. Open VSCode
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Vireo Language"
4. Click Install
