Cryptography

Signature: Ed25519 (RFC 8032)
Hash: BLAKE2b-256 (RFC 7693) - 1.53x faster than SHA-256
Canonical form: RFC 8785 JCS
Wire: 96-byte header + RFC 8785 JCS payload
DID: did:vireo:<base64url(BLAKE2b-256("agent:name"))>

Benchmarks (measured)

Wire size: up to 2.58x smaller than JSON (small messages)
BLAKE2b-256: 1.69 us (1K) vs SHA-256: 2.59 us
Ed25519: sign 39.3 us, verify 66.4 us
Serialization: 0.42x-0.90x slower than raw JSON (honest)

Vireo trades raw speed for deterministic bytes - required for cross-language Ed25519 signatures.
