🌐 Open Wire Protocol v3.1

Canonical binary protocol. 96-byte header + RFC 8785 JCS payload. Measured: up to 2.58x smaller than JSON for small messages. Serialization is 0.42x-0.90x slower than raw JSON, because canonicalization + BLAKE2b hashing are performed.

🌐 Open Wire Protocol ready.

🔐 DIDs & Trust Bootstrap v3.1

Decentralized Identifiers. Format: did:vireo:<base64url(BLAKE2b-256("agent:name"))>. Ed25519 challenge-response trust bootstrap.

🔐 DIDs ready.
