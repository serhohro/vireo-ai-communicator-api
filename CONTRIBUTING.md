## 🎯 HOW CAN I CONTRIBUTE?

### 🐛 Report Bugs

If you find a bug, please create an issue with:
- A clear title and description
- Steps to reproduce the bug
- Expected behavior vs actual behavior
- Screenshots if applicable
- Environment details (OS, Python version, etc.)

### 💡 Suggest Features

Have an idea for Vireo? Open an issue with:
- A clear description of the feature
- Why it would be useful
- How it should work
- Any potential drawbacks

### 📝 Improve Documentation

Documentation is crucial for adoption. You can help by:
- Fixing typos and grammar
- Adding examples
- Writing tutorials
- Translating documentation
- Improving API docs

### 🔧 Write Code

Areas where we need help:
- **Core Language**: Implement new features, fix bugs in the interpreter
- **LLM Integration**: Add new LLM providers
- **Multi-Agent System**: Improve agent roles and orchestration
- **Performance**: JIT compilation, GPU support, optimization
- **Security**: Cryptography, authentication, sandboxing
- **Tooling**: VS Code plugin, CLI tools, package manager
