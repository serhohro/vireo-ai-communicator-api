# 🤝 Contributing to Vireo

First off, thank you for considering contributing to Vireo! 🌟

We welcome contributions from everyone. Here's how you can help:

---

## 🎯 Ways to Contribute

### 1. Code Contributions
- 🐛 **Bug fixes** — Help us fix issues
- ✨ **New features** — Add new functionality
- 🔧 **Improvements** — Optimize existing code

### 2. Documentation
- 📝 **Write docs** — Improve our documentation
- 📚 **Examples** — Add more examples
- 🌐 **Translations** — Translate to other languages

### 3. Community
- 🗣️ **Share** — Tell others about Vireo
- ⭐ **Star** — Star the project on GitHub
- 🐛 **Report issues** — Report bugs and suggest features
